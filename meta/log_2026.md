## 2026-05-07 — Step 3 / Pre-DUN UnitNode Bridge

### Summary

The first working pre-DUN object workflow was added.

This layer is not a full DUN, but it tests the key bridge between the world voxel grid and the future DUN model:

```text
World voxels
-> extracted local payload object
-> move / rotate as one unit
-> bake back into world
```

---

### Changed

- Added `LabVoxelObject`.
- Added `VoxelPayload`.
- Added `LabObjectRegistry`.
- Implemented Extract Copy.
- Implemented Extract Cut.
- Added selected object switching.
- Added selected object delete.
- Added object bounds / pivot gizmos.
- Added object render preview.
- Added object movement as one mass.
- Added bake selected object back to world.
- Extended save/load: lab snapshot now saves detached objects.
- Added C4 orientation state.
- Added C4 yaw preview.
- Added rotated bake back to `LabVoxelWorld`.

---

### Current Technical Slice

Step 3 records the pre-DUN UnitNode bridge:

- `LabVoxelWorld` remains the world storage truth;
- `LabVoxelObject` stores local payload;
- object movement changes object origin, not world voxels;
- C4 orientation is stored separately from address/origin;
- bake applies content rotation when writing back into the world;
- render remains a preview/debug layer, not the source of truth.

---

### Notes

- This is not a full DUN.
- Dynamic DUN quaternion rotation is not implemented yet.
- Physics/collider for the object layer are not connected yet.
- UI/HUD is temporary and requires a window rebuild.
- Save/load remains a lab snapshot, not a production format.
