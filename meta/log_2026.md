## 2026-05-07 — Step 3 / Pre-DUN UnitNode Bridge

### Summary

Добавлен первый рабочий pre-DUN object workflow.

Этот слой не является полноценным DUN, но проверяет ключевой мост между мировой voxel-сеткой и будущей DUN-моделью:

```text
World voxels
-> extracted local payload object
-> move / rotate as one unit
-> bake back into world
```

---

### Changed

- Добавлен `LabVoxelObject`.
- Добавлен `VoxelPayload`.
- Добавлен `LabObjectRegistry`.
- Реализован Extract Copy.
- Реализован Extract Cut.
- Добавлено переключение selected object.
- Добавлено удаление selected object.
- Добавлены object bounds / pivot gizmos.
- Добавлен object render preview.
- Добавлено движение object как единой массы.
- Добавлен bake selected object back to world.
- Save/load расширен: теперь lab snapshot сохраняет detached objects.
- Добавлено C4 orientation state.
- Добавлен C4 yaw preview.
- Добавлен rotated bake back to `LabVoxelWorld`.

---

### Current Technical Slice

Step 3 фиксирует pre-DUN UnitNode bridge:

- `LabVoxelWorld` остаётся world storage truth;
- `LabVoxelObject` хранит local payload;
- object movement меняет object origin, а не world voxels;
- C4 orientation хранится отдельно от address/origin;
- bake применяет content rotation при записи обратно в world;
- render остаётся preview/debug layer, не source of truth.

---

### Notes

- Это не полноценный DUN.
- Dynamic DUN quaternion rotation пока не реализован.
- Physics/collider для object layer пока не подключены.
- UI/HUD временный и требует window rebuild.
- Save/load остаётся lab snapshot, не production format.
